# Finding a member by search or ID scan

## Steps

1. Open Members and choose the search field: name, DOB, government/state ID, membership number or membership type.
2. Enter the requested value. DOB searches accept MM/DD/YYYY or YYYY-MM-DD; membership numbers are numeric. Name/ID searches are primarily exact matches, with supported capitalization/normalization variants; this is not a broad fuzzy directory search.
3. Review name, membership number, DOB, ID state and membership status before opening a result. Use paging when more results exist. Check whether the DNA-only filter is hiding other members.
4. Alternatively, open the ID-scanning action and scan a supported ID. Review the parsed details and any existing matches. Do not assume that a decoded card proves identity or admission eligibility.
5. If no matching member is found and you have creation rights, use the offered new-membership flow. Creation also performs its separate similarity check before checkout.

## If no result appears

Confirm the selected business, field and spelling/format. Try membership number or DOB when a name changed. A failed request is not the same as no match; reconnect/retry first. Opening an existing member lets you review details, history, notes and attached files before starting an order or check-in.
