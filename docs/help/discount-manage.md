# Creating and managing discount codes

## Before you start

The owner grants Manage discount codes in Users & permissions. It is independent of selling, refunds and product editing. Open POS → Discount codes.

## Steps

1. Create a code with a descriptive name. Codes use up to 32 letters, digits, underscores or hyphens and are normalized to uppercase. The code identifier is fixed after creation.
2. Choose Percentage off (0.01–100%, up to two decimals) or Dollar amount off; enter its value.
3. Choose eligible products/categories and optional retail/membership/rental types. Product and category choices form a union; type choices further restrict it. Empty choices mean unrestricted in that dimension.
4. Set Minimum eligible spend, optional Maximum savings, Starts/Ends in the workstation's local time, and optional total/per-member use limits. Start is inclusive; end is exclusive. Uses count completed orders, not item units.
5. Set Active, review notes and save. Confirm the saved rule before sharing the code.

## Maintaining a promotion

Edit to change eligibility/value/dates, deactivate to pause, or archive to stop availability while retaining identity/history. Restore by editing when offered. Existing counts never reset; use a new code for a fresh usage budget. You cannot lower the total limit below recorded uses. Per-member limits need an existing primary member at checkout. If another manager edited the rule, reload before saving; do not overwrite stale details. Refunds retain paid savings and do not replenish uses.
