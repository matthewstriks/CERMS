# Closing another staff member's register

## Before you start

The independent Close other staff’s registers permission is required; Close own register alone is insufficient. The owner retains full access. You can close only an open register in your selected business, and do not need an open drawer of your own for this manager action.

## Steps

1. Ask the cashier to finish work and resolve any unconfirmed sale/refund/drop before closure.
2. Open Registers and locate the correct staff member's open register.
3. Select Close register beside that drawer. Check owner and opening information before entering counts.
4. Count actual ending bills/coins, review expected cash/over-short and add any closing note.
5. Confirm and wait for closure. Review/print the saved closeout if needed.

## What is recorded

The original cashier remains the register owner; the actual verified closer and closing time are saved separately. Original opening information, ledger totals and closed counts are preserved. New sales cannot commit after closure, and the cashier can later open a new shift.

## If something fails

Recheck saved status before retrying an uncertain close. A print error does not undo closure. Older closeouts may show Not recorded for closer information; do not infer the closer was the current viewer. This action cannot transfer a drawer, change another person's opening counts or edit a previously closed register.
