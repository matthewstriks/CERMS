# Installing CERMS on Windows or Mac

## Before you start

Get the authorized CERMS installer/download from the owner or the published release location. Do not use an AI-invented download URL. Keep your login details private. Model installation is a separate optional support setup, not part of the CERMS installer.

## Windows

1. Download the Windows installer intended for your computer.
2. Close existing CERMS work safely before replacing an installed version.
3. Run the setup wizard, review its destination/options and finish installation.
4. Launch CERMS, check Settings → Version and sign in. For automatic updates, use an update-enabled installed release.

## Mac

1. Download the Mac DMG from the authorized release.
2. Open the disk image and drag CERMS to Applications using its installer layout.
3. Launch the installed Applications copy and sign in, rather than continuing to run from the disk image.
4. The first signed update-enabled build is a manual installation; later signed releases can auto-update. An unsigned build stays a manual-update installation.

## If blocked

Record the exact operating-system/app message and ask the owner/support to verify the correct signed installer. Do not disable system security, strip quarantine or bypass signature verification on the AI's advice. Installer appearance does not establish signing/notarization status. Installing CERMS does not create a staff account, migrate legacy data or automatically download the AI model.
