# Editing a rental, in/out status or waitlist

## Before you start

Use point of sale permission is required. Only active rentals in your saved business can be managed. In/out describes temporary presence; it does not end an admission.

## Steps

1. On Overview or Admissions & rentals locate the active rental and use View/Edit or the row's Edit action.
2. Check member, rental type, assignment and expiry.
3. Edit Assigned Room/Number, rental notes, inside/outside or waitlist as needed.
4. Save and wait for confirmation. Check the updated row on the active-rental screen.

## What is unchanged

Editing does not charge payment, renew time, end the visit or release admission. You cannot enter an arbitrary rental expiration. Use Renew for paid time; use Check out to complete a visit. Room/number text is not an availability reservation or conflict detector.

## If another staff member changed it

Refresh/reopen the latest rental, review its current state and reapply only the intended changes. A revision conflict protects another person's edit or renewal; do not repeatedly save an old form. Save or discard unsaved edits before starting checkout. Completed rentals cannot be edited or renewed. If a visit remains visible after a confirmed change, check connection/refresh before starting a second action.
