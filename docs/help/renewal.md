# Renewing an existing membership

## Before you start

You need Use point of sale permission, an available membership product and your own open register. Membership renewal is separate from paid rental renewal and does not require general member-edit permission.

## Steps

1. In POS use Add membership or select a membership product. An expired member's Create order/check-in flow may open the renewal prompt automatically.
2. Choose the plan and existing recipient. Review current expiration, active/expired status, duration, price and calculated expiration.
3. For active membership choose Add to existing expiration to keep remaining time, or Start from today to replace remaining time. Expired/missing-expiration memberships automatically start from successful checkout time.
4. Select Add membership to order. Additional units for this recipient use the same product/time choice; review their combined duration.
5. Complete the linked order. You can add rentals and other recipients before payment.

## Result and limits

Previews are estimates; final expiration uses successful checkout time. Canceling the dialog/payment adds no time. Retry the original uncertain sale to avoid double renewal. An expired-member prompt can offer Continue without renewal: that leaves expiration unchanged and allows eligible rental checkout. Skipping does not mark the membership active. DNA and existing-admission checks still apply. Product durations use their configured hour/day/week/month/year conversion, not a freely entered expiration date.
