# Building an order in Point of sale

## Before you start

Use point of sale permission and your own open register are required to complete sales. CERMS records payments collected outside the application; it does not charge a card. Check the selected business.

## Steps

1. Open Point of sale, or use Create order on a member to start a linked order.
2. Add active permitted products using search, an Enter-terminated barcode scan, Favorites or expanded categories. Favorites remain at the top; click a category heading to expand/collapse it.
3. Review each line's price, quantity and recipient/room details. Ask-for-price products require a price. Remove an incorrect line before payment.
4. Link the intended primary member. Assign membership units and rental recipients individually for group orders; a customer label alone is not a linked member.
5. Apply any eligible discount code or authorized product waiver and review totals. Complete required member-note reviews.
6. Select Take payment and follow the payment steps; a negative payout uses Record payout instead.

## If blocked

Check your open register, POS permission, product availability, inventory, required recipient/room fields and tax configuration. Refresh changed products rather than guessing their price. A normal local draft is not a completed sale. An uncertain submitted order must use the original Retry action; use the separate recovery guide before discarding it.
