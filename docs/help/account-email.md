# Changing and verifying your login email

## Before you start

Open Settings → Account settings. You need your current password and access to the new inbox. The login is shared with legacy CERMS, so changing this email affects signing in there too. A staff administrator's profile-email edit does not change this login address.

## Change email

1. In Change email, enter New email and Current password for email change.
2. Select Send email change link. Your current login email remains active until verification succeeds.
3. Open the message in the new inbox and follow its confirmation link.
4. Return and select Refresh verification. If your session expired, sign in with the verified new email first, then refresh verification.
5. Check that the login address and verification status are correct. Refresh verification deliberately synchronizes a verified login address to your CERMS 5 profile email.

## Verify the current address

Select Send verification email when available, follow the inbox link, then select Refresh verification. Respect the displayed resend timer. Merely opening Settings or signing in does not synchronize profile emails.

## If it fails

Check spam/junk and the address entered. A wrong current password prevents the change. Use a fresh verification link if the previous one expired. Never send support your password or verification link; describe the error instead.
