# Changing your password while signed in

## Before you start

This changes your shared CERMS login, including legacy CERMS. It changes only your own password; staff-profile administration cannot reset another person's shared credentials.

## Steps

1. Open Settings → Account settings → Change password.
2. Enter Current password.
3. Enter a new password of 12–128 characters in New password and repeat it exactly in Confirm new password.
4. Select Change password and wait for confirmation. If asked to sign in again, use the new password.

## If it fails

Mismatched confirmation or an invalid length must be corrected before saving. A wrong current password prevents the change. If you cannot remember it, sign out and use Forgot password on the opening screen rather than guessing repeatedly. Check internet if the request cannot reach the service.

## Handling passwords

Do not put passwords in AI chat, notes, messages or support tickets. Account changes do not change business access or permissions. A profile/access problem needs the owner even when the password itself works.
