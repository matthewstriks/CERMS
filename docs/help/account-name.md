# Changing your own display name

## Before you start

Every signed-in staff member can edit their own display name in Settings → Account settings. This does not require staff-administration permission.

## Steps

1. Open Settings and find Account settings.
2. Check that you are signed in to your own account.
3. Edit the display name and select Save display name.
4. Wait for confirmation and the refreshed profile before navigating away.

## What changes

This updates your CERMS 5 profile name. It does not rename a customer, change your login email/password, grant permissions or update a legacy profile. Historical receipts and notes may retain names saved when those events happened.

## If saving fails

Check your connection. If another update changed the profile, reload the current details before saving again. A removed or unavailable staff profile cannot be repaired by changing its name; contact the owner. To edit another staff member, use the separate Users & permissions workflow and its Edit staff profiles permission.
