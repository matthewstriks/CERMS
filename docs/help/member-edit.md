# Editing a member record

## Before you start

You need Edit member records permission in the selected business. This is different from changing a staff profile or selling a membership renewal. Use the paid membership workflow when collecting payment for new time.

## Steps

1. Find the customer in Members and open Edit for the correct record.
2. Review the existing name, DOB, ID state/type/number, email, phone, membership label and expiration before changing them.
3. Edit the needed fields. Keep the current membership type if you are not deliberately changing it. Review any expiration adjustment; choosing another plan in this editor does not collect money or automatically renew it.
4. Set Read notes / tagged when the member's notes require review during an order.
5. Save and wait for confirmation. Reopen the record to check the saved details if needed.

## Limits and recovery

The membership number, business and original creation information stay protected. Waiver, notes, check-in state and unrelated fields are not replaced by this editor. Do not change DNA here; use the notes/DNA action and record its reason. Duplicate identity conflicts and stale records require review rather than overwriting another person. If another staff member changed the record, reload and reapply only your intended edits. A contact-email change affects the customer profile, not a staff login or a previously sent receipt.
