# Printing a saved register closeout

## Before you start

The register must be saved as closed. Business-scoped readers may review/reprint the report; a report preview is not itself a register-close action.

## Steps

1. After successful closure, review Register closeout report, or find the register in Closed registers and select Print closeout.
2. Check the original owner, closer when recorded, opening/closing times, denominations, expected/counted cash, over/short and payment totals.
3. Select an installed receipt printer and appropriate 80 mm/58 mm width. These workstation preferences are shared with receipt printing.
4. Select Print closeout report and confirm through the offered printing controls. Closing a register does not automatically spool a print job.

## If printing fails

Use Retry loading report for a read failure; printing remains disabled until a valid report loads. For a printer failure check the operating-system printer, driver, paper and connection, then retry printing. The register remains closed: never close it again to produce paper.

## Reading the report

Older records may show Not recorded for the closer. The receipt header/address is read from current business settings at print time, while saved shift counts/totals remain unchanged on reprint. The report is a shift reconciliation, not proof of card settlement or a live editable cash ledger.
