# Applying a discount code to an order

## Before you start

Cashiers with POS permission can apply a known code. Creating/editing codes requires separate Manage discount codes permission. One code applies per order; payouts cannot use codes and waived lines receive no additional discount.

## Steps

1. Build the cart and select the intended primary linked member, especially for a per-member promotion.
2. Enter the code in the cart and select Apply code. Codes are case-insensitive.
3. Review the accepted code, eligible savings, tax and total. A fixed discount cannot exceed eligible spend; a percentage may have a savings cap.
4. If you change products, quantities or the linked member, allow the code to revalidate before payment.
5. Complete the sale once. Failed/canceled orders do not consume uses; the same saved-order retry does not consume another use.

## If rejected

Check spelling, active/date window, eligible products/categories/item types, minimum eligible pre-tax spend and remaining total/per-member uses. Per-member limits require an existing primary member, not a pending new member or every person in a group. A rule edited during payment must be reapplied/reviewed. Correct or remove a rejected code; it is not silently dropped. Refunds use the discounted paid amounts and do not restore code usage. Ask a code manager to review configuration rather than overriding prices to imitate an invalid code.
