# Updating CERMS and Mac installation

## Steps

1. Open Settings and check the installed Version/update status. Use Check for updates in an installed update-enabled build.
2. Review What's new when offered. Allow the download to finish; keep using the current version while it downloads if the app permits.
3. Resolve pending sales/refunds, save work and finish time-sensitive actions before restarting.
4. When ready, confirm the offered install/restart action, or quit normally for a downloaded ready update to install on exit.
5. Reopen CERMS, check the version and sign in. A downloaded file alone is not proof the new version is installed.

## Mac requirements

Automatic Mac updates require a properly signed update-enabled installation. Install the first signed Mac build manually in Applications. Unsigned/manual-update builds need an authorized manual download/install; do not bypass operating-system security or signature checks.

## If the check/download fails

The current version can remain usable. Check internet and retry later. Report whether failure was immediate or occurred during download, the exact message, installed version and Windows/macOS details. A release-feed file opening in a browser does not prove the app downloaded/verified an installer. Do not promise a newer release exists or that a failed check has been fixed without evidence. Development previews do not auto-update. Updates are supplied only when the owner publishes a release; editing source/docs does not publish one.
