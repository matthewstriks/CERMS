# Searching messages and understanding read receipts

## Find a conversation/message

1. In Messages use Search conversations and the Unread filter to find a thread. Load older conversations when needed.
2. Open the conversation and use Search this conversation → Search messages for message text.
3. Use Search older history to search further saved pages; an initial page search is not automatically the entire history.
4. Leave history search/older browsing and return to the bottom to review current messages.

## What Sent and Read mean

Sent confirms the server-saved message, not a device notification. Read advances when the recipient has fresh data, a visible/focused window, the conversation at the bottom and no active history search. Opening another screen, a hidden window or scrolling old history does not acknowledge new messages. Group receipts identify readers. The displayed last-read time is the person's latest read position, not necessarily their first view of every earlier message.

## Unread indicators

The navigation badge and conversation markers reflect saved unread state, not an external inbox. Sending a message does not automatically mark all incoming history read. If a receipt update fails, use Retry read receipt; reconnect for live-data failures. Missing sound alone does not imply a missing message: check saved mute/volume and burst coalescing separately. Message history is participant-private and business-scoped; there is no owner override to inspect unrelated conversations.
