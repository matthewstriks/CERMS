# Starting a private staff conversation

## Before you start

Messages connects staff in the same saved business. Only participants can read a conversation; owner status does not bypass this. A staff member who moved businesses may no longer be eligible for new delivery.

## Steps

1. Open Messages → New conversation.
2. Search by staff name or ID. Select one person for a direct conversation or several for a group, up to ten participants including yourself.
3. Start/open the conversation and verify its participants. The same participant set resumes an existing conversation instead of creating another copy.
4. Type your message. Enter sends; Shift+Enter inserts a new line. Messages may be up to 10,000 characters.
5. Wait for saved delivery confirmation before assuming it was sent.

## If sending is uncertain

Use Retry same message with its original text/request rather than typing a second copy. Reopening Messages within the same session retains an in-memory pending send, but signing out/changing identity clears that recovery state. Drafts are not a promised disk backup across app restarts. Use Reconnect messages for connection issues.

## Limits

Messages/participant sets cannot be edited or deleted through the current app. New participant groups require a new conversation. Messaging does not send external emails or push notifications. Avoid passwords and unnecessary private customer information; private staff chat is different from the AI conversation evaluation email and support-ticket workflow.
