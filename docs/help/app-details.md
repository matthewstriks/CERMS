# Finding app details, menu commands and keyboard shortcuts

## Copy application details

1. Open Settings → About CERMS, or About CERMS in the Mac CERMS menu / Windows Help menu.
2. Review the installed version and platform information.
3. Select Copy app details and include that information in a support request when needed. Use Done or the native close control to return.

## Menu shortcuts

1. With the required signed-in rights, File → New Member uses Command+Shift+N on Mac or Ctrl+Shift+N on Windows. Current creation remains owner-only in Dev System.
2. File → New Order uses Command+Shift+O / Ctrl+Shift+O when POS access is available. Review any existing draft/replacement confirmation; this does not complete a sale.
3. Use View → Zoom In, Zoom Out or Reset Zoom when text is too large/small. The workspace normally maximizes after sign-in; the smaller login window is intentionally fixed in size.
4. Check for Updates is also available in the Mac CERMS menu / Windows Help menu, using the same installed-build updater rules as Settings.

## If unavailable

A disabled shortcut respects the current account/business permissions and active dialog/workflow. It is not a way around a permission gate. Developer tools/reload commands are development-only, not support instructions for customers. A version copied from About identifies the running app, whereas a downloaded installer filename alone does not establish what version is installed.
