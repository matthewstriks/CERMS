# Checking in a member with a rental

## Before you start

You need POS permission and your own open register. The member must belong to the selected business, have usable membership data, have no DNA restriction and not already be admitted. An expired membership may proceed after the optional renewal prompt; skipping does not renew it.

## Steps

1. In Members, find the correct person and choose Check in, or link them in POS and add rental products.
2. If prompted about expired membership, add a renewal or deliberately Continue without renewal.
3. Select each rental product/unit. Review Assigned member for every unit; group orders can use different recipients.
4. Enter the required Assigned Room/Number for each rental and review any member-note acknowledgements.
5. Continue to order, add other items if needed, record payment and complete checkout once.
6. Confirm that the visit appears in Overview and Admissions & rentals with the right recipient, room/number and expiration.

## Result and limits

Admission starts only after successful checkout. Canceling/failed payment creates no visit. Assignment is free text; CERMS does not guarantee room uniqueness or maintain room-availability inventory. A current visit blocks a duplicate admission. If an order response is uncertain, retry the original order rather than checking the customer in again. Rental duration and membership expiration are separate; buying a rental does not automatically renew membership time.
