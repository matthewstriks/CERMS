# Choosing whether a refund also cancels membership or rentals

## Before you start

Use Return / refund on the original receipt with refund permission and your own open register. Leaving a service-cancellation option unchecked refunds money while keeping the membership/visit. Check all affected recipients in a group order.

## Steps

1. Select the return quantities. Automatic cancellation requires every remaining unit of that product line, not a partial unit return.
2. Choose Undo membership purchase only if its time should be reversed. A new purchase expires membership while retaining the customer; an eligible renewal restores the saved prior expiry/plan.
3. Choose Cancel related rentals only if those visits should end. Recover rental items and complete the required confirmations first. The option affects all recipients linked to that product line.
4. Review the refund reason, payment amounts and confirmations, then submit once. Check the saved refund result before doing another operation.

## When cancellation is refused

Later membership changes/renewals or older receipts without trustworthy reversible history prevent automatic undo. Later rental renewals prevent canceling through an older receipt. Unrelated active rentals can block membership undo; check them out or resolve applicable related rentals appropriately. Financial-only refund remains separate from manual manager review; do not alter expiration to disguise a blocked cancellation.

## Effects

Other active rentals keep the member admitted. Ending the final related visit releases check-in. Rental-renewal cancellation ends that visit; it does not merely subtract time. Members, original receipts and history are not deleted. Refunds do not restore discount-code usage counts.
