# Uploading, viewing and downloading member files

## Before you start

Open a saved member in your selected business. Viewing/listing files uses normal member access; uploading needs Edit member records permission. Each non-empty file may be up to 20 MB. Multiple selected files upload in sequence. These originals are separate from product display images.

## Steps

1. Find the member and open View, then the files/attachments section.
2. Check the person's identity before choosing Upload member files. Select the image, PDF or other documents you intend to attach.
3. Wait for completion. Review the saved filename, uploader and date when shown.
4. Use View for supported images/PDFs. They open in the external browser through a temporary private link.
5. Use Download to obtain the original file. Other file types download rather than running inside CERMS.

## Recovery and limits

Use Retry for pending uploads instead of selecting all files again. An expired viewing link needs a fresh View/Download action; it does not mean the original file was deleted. A removed/foreign member or revoked permission prevents access. Existing waiver/legacy attachments remain visible. Uploading a file does not mark a waiver signed. Member-file deletion and new waiver-signing are not available. Original bytes and useful filenames are retained; there is no product-image-style optimization of these files.
