# Confirming required member notes during an order

## When required

A member marked Read notes / tagged requires note review when linked to an order or assigned as a membership/rental recipient. Each involved flagged member must be reviewed separately.

## Steps

1. In Read member notes, check the member name and read the displayed current notes.
2. Select Confirm read only after reviewing them. Canceling the popup does not acknowledge anything.
3. Review the other flagged recipients in a group order when prompted.
4. Continue payment after all required reviews are confirmed.

## If the popup returns

Notes are checked again before payment. A new note, removal or DNA change makes an earlier acknowledgement outdated, so read the current version and confirm again. This is expected protection, not a reason to clear the tag or delete notes.

## If notes will not load

Check internet and retry. Payment stays blocked while required notes are unavailable. Do not start a replacement transaction or remove the recipient just to bypass review. Reading a DNA reason does not authorize admission or renewal for a DNA member. Acknowledgements apply to the current order and must be obtained again for a new order; note text is not printed on customer receipts.
