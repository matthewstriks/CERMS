# Signing in and resetting a password

## Before you start

Use your staff login email, which may differ from the email displayed on a CERMS 5 staff profile. An internet connection is required. Creating a customer membership does not create a staff login.

## Sign in

1. Enter your staff email and password on the opening screen and select Sign in.
2. Check the displayed business after sign-in.
3. If the password is rejected, check the email, typing and Caps Lock. Avoid repeatedly guessing a password.

## Reset a forgotten password

1. On the opening screen, select Forgot password and enter the login email.
2. Request the reset email, then check that inbox and spam/junk.
3. Follow the reset link and return to CERMS to sign in with the new password. The shared login password also affects legacy CERMS.
4. If the link expired, request a fresh one. If requests are temporarily limited, wait before retrying.

## If sign-in succeeds but the workspace does not open

A valid login still needs a CERMS 5 staff profile and access to an existing business. Ask the owner to review access; do not create a customer record to fix it. Login-page Support works without signing in. Include the error and application version, never your password, reset link or authentication token.
