# Returning items and recording a refund

## Before you start

You need Process returns and refunds permission and your own open register. Selling permission alone is insufficient. CERMS records external refunds; perform the real card/gift-card reversal on its terminal/service. It does not process money or alter a gift-card balance.

## Steps

1. In POS → Sales & payments or History, find the original receipt and open Return / refund.
2. Select return quantities within the remaining quantities shown.
3. Deliberately choose Restock returned items only for stock actually received and a currently tracked product. Review service-cancellation options separately.
4. Enter the required reason. Review the refund amount/tax, then enter outgoing amounts across the allowed original payment methods. Each method is capped by its remaining paid amount; cash must fit your drawer.
5. Complete the displayed item/payment confirmations, then submit once.
6. Wait for the separate saved refund receipt, which links to the original order. Print it if needed.

## Result and recovery

Partial/full returns use original paid prices, allocated discounts and tax; current prices/promotions do not replace them. The original receipt remains unchanged. Refunds belong to the recording date and issuing register, not the old closed shift. If uncertain, retain/reopen the pending return and retry the same request. Payouts and refund receipts themselves cannot be refunded again. A financial refund leaves services active unless the cancellation option was explicitly selected.
