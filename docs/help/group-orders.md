# Combining multiple members, memberships and rentals in one order

## Before you start

Existing-member purchases/rentals need POS access. New memberships retain the owner-only Dev creation restriction. One order can involve up to 50 members, 20 new memberships, 100 rentals and 100 unique product lines; existing-member membership units also have their displayed limit.

## Steps

1. Start an order and select its primary linked member.
2. Use Add membership to assign a plan to an existing member or create an authorized pending new member. Repeat for each membership recipient.
3. Add rental units. For each unit, review Assigned member and enter Assigned Room/Number. Unassigned units default to the linked member; explicit recipient choices survive a later primary-member change.
4. Review the cart line quantities and each membership/rental assignment. Multiple units of one product remain grouped, with separate recipient/unit details.
5. Confirm required notes for every flagged recipient, record the full payment and complete the order once.

## Result and recovery

All new members, purchased membership time, rental visits, stock and register totals are saved together only on successful checkout. Canceling/failed payment fulfills none. Removing a membership product also removes its related pending forms/assignments; review before removal. Changing the primary member alone does not reassign explicit recipients or each person's time choice. Retry the original order after an uncertain result rather than rebuilding the group and risking duplicates.
