# Adding and removing member notes

## Before you start

Same-business signed-in staff can add notes. Removing notes needs the independent Remove member notes permission. Note removal and DNA clearance are separate actions.

## Add a note

1. Find the member and open View.
2. In the notes section, review existing entries first.
3. Enter the note and use the add/save action. Include the information needed by other staff without putting passwords or unrelated private information in it.
4. Wait for confirmation. New notes display the verified staff name and saved timestamp. Older notes may have no attribution; missing information is not invented.

## Remove a note

1. With Remove member notes permission, choose the removal action on the specific entry.
2. Confirm the selected note. Removal cannot be used to clear a member's DNA restriction.
3. Wait for confirmation before removing another entry.

## If saving is uncertain

Use Retry note save with the same pending change. Do not add a second copy of the same note because the first response was lost. A note added, removed or changed after order review requires the cashier to review current notes again. For DNA, use Save DNA status with a reason; for mandatory review, use Read notes / tagged on the member record.
