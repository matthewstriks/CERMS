# Setting up CERMS Assistant

## Before you start

CERMS Assistant is optional. It uses your computer's Ollama runtime and the fixed Qwen2.5 1.5B model, approximately 1 GB plus Ollama. No paid AI account, subscription, API key or per-question fee is required. Internet is needed for setup, and your computer supplies the processing/storage.

## Steps

1. Select the CERMS Assistant help icon beside Report a bug, or CERMS Assistant on the login page. Bug reports open separately.
2. If Ollama is missing/not running, select Download Ollama. Install and open it from the official Windows/Mac page that opens.
3. Return to CERMS and choose I installed Ollama/check setup again.
4. Select Download CERMS Assistant and wait for the progress to complete. Pause/retry is available; an incomplete download does not enable answers.
5. Keep Ollama running, enter a CERMS question and expand Help articles to check the instructions.

## If setup fails

Check disk space, internet during download and that Ollama is actually running. Retry detection/download; Ollama can reuse its downloaded data. CERMS updates retain models in Ollama's storage and do not normally download them again. Slower machines take longer. Setup through this flow is offered for Windows/Mac, not Linux. Do not select a paid/cloud alias as a workaround. You can use the separate Report a bug / login Support action without completing assistant setup; installed local answers can work offline afterward, while ticket/email delivery still needs internet.
