# Checking out and completing a rental visit

## Before you start

You need POS permission for the active rental's business. Rental checkout is distinct from paying an order at POS and from issuing a refund. Save or discard unsaved rental edits first.

## Steps

1. On Overview or Admissions & rentals, locate the correct active visit and select Check out or its View → Check out rental action.
2. Review the member, room/number, rental details and current expiry. Confirm the physical rental is finished.
3. Select both The rental is completed and All required items have been returned.
4. Select Confirm rental checkout and wait for confirmation. Canceling the dialog saves nothing.
5. Check that the completed visit disappears from active rentals. Other active units for that person remain active; completing the last visit clears their check-in.

## Limits and recovery

This action records completion and item-return confirmation; it does not itself add an overdue fee, take payment, refund money or change stock/register totals. Record any separately authorized purchase through normal POS procedures. In/out alone never ends a visit. If an edit or paid renewal changed the visit while the confirmation was open, reopen and review it. Retry the offered original confirmation after an uncertain result; do not start a duplicate visit or alter the member's check-in manually. Completed visit history is retained.
