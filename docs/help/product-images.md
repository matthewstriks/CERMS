# Adding or replacing product images

## Before you start

Use Create and edit products and categories permission. JPEG, PNG and WebP sources are supported. A square image around 512 × 512 is recommended, not required. Original source size/dimensions have no application rejection cutoff; very large images may take longer to prepare.

## Steps

1. Open Create/Edit product in Products.
2. Select an image and review the preview. CERMS prepares an optimized display copy automatically; selecting a file alone does not upload it.
3. Save the product and wait for image preparation, upload and product-save confirmation.
4. Reopen the editor or POS to view the saved image. A text tile remains usable if an image cannot load.
5. To replace the image select another and save. To detach it use Remove image, then save.

## What is stored

Only the optimized display copy is uploaded for product use; the source file is not changed locally or kept remotely as an original. Removing/replacing an attachment does not delete old stored objects. Categories do not support images. These rules differ from member-file uploads, which retain originals with a 20 MB per-file limit.

## If saving fails

Retry the current save rather than selecting/uploading repeatedly. A successful image upload can be retained for a failed product-save retry. Check business/permission and the current product if its version changed. Do not bypass authentication with a public image link.
