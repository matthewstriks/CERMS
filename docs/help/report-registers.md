# Reporting on register closeouts

## Steps

1. Open Reports & analytics, apply the intended date range and select Register closeouts.
2. Review registers closed during that period, including original owner, actual closer when recorded, opening/closing times and shift transaction totals.
3. Compare opening cash, expected ending cash, counted cash and over/short. Review refunds, payouts and drops when explaining expected cash.
4. Export register closeouts as CSV or open the saved register's closeout print action for a physical report.

## Date rules

The selected range chooses registers by closing time, but each row includes the entire shift's totals even if it opened before the range. This can differ from sales limited to that calendar day. Open registers are excluded. Refunds belong to their issuing register, not the original sale's older closed shift.

## Older and failed data

Where no modern POS ledger exists, expected cash can fall back to saved opening cash; legacy cash movements are not invented. An unknown closer displays Not recorded. Unavailable ledger/source data must be retried or reviewed, not treated as zero. Closed counts are immutable. Exporting, printing or changing a report date cannot repair a saved discrepancy; document the issue for an authorized manager using its original references.
